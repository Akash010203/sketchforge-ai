## 1. Synthetic Dataset

**Source:** `datasets/synthetic/` — generated by `synthetic_generator.py`
**License:** MIT (project-owned; no upstream restrictions)
**Sample count:** 510 PNG sketch images + 510 ground-truth JSON annotation files + 1 manifest.json = **1,022 files**
**Conditions:** clean, blur, noisy, shadow, thick-stroke, thin-stroke
**Layouts:** dashboard, landing_page, login_page, mobile_form
**Bounding boxes:** every sample has paired `{label, x, y, w, h}` annotations
**Usage:** always available; no network access required

## Intended Use and Limitations

1. **Synthetic data** supports reproducible pipeline and evaluation work.
   Do not benchmark real-world sketch-recognition performance on synthetic-only results.
2. **Keep gated-dataset results separate** from open-data results in publications.
3. **Attribution** is required for all CC-BY-4.0 and ODC-By-1.0 sources.
4. **The IAM-line** dataset is restricted to non-commercial research.
5. **WebCode2M and The Stack Dedup** have not been fully audited at the file level;
   per-file SPDX scanning is recommended before large-scale commercial training.
6. Evaluation metrics trained on the synthetic set alone are not representative
   of performance on real hand-drawn sketches.  Use SALT-NLP / ImageCLEF splits
   for realistic evaluation.
