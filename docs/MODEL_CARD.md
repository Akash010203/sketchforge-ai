# Model card

No SketchForge model has been trained or released. Sketch interpretation currently relies on deterministic computer vision. The component detector package is experimental infrastructure and has not been validated as a working model.

When a model is trained, update this card with its architecture, initialization method, dataset sources and licenses, training configuration, held-out evaluation metrics, hardware, checkpoint hash, intended use, and known limitations.

Models hosted by external providers must be identified as provider-hosted. Do not describe them as models trained locally by SketchForge.
