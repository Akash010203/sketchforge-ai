# Sample sketches

Synthetic sketches produced by `scripts/make_sample_sketches.py` from our own generator. They imitate pen strokes, paper, shadows and noise but are **not** photographs of human drawings; use them for the demo and tests only. `*.truth.json` holds each layout's ground-truth component boxes in sketch pixels.

To try your own drawing, use *File > Import sketch* (or `sketchforge demo --image PATH`).
